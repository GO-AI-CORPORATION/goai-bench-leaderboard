# GO AI Bench Leaderboard

Open benchmarking leaderboard for NLP models on Burkinabè languages — **Mooré** & **Dioula** — across ASR, MT, and TTS tasks.

Built with the [GO AI Bench toolkit](https://github.com/GO-AI-CORPORATION/goai-bench) under a **UNICEF WCARO** consultancy.

## Features

- **Multi-task**: ASR, Machine Translation (both directions), Text-to-Speech
- **Multi-domain**: General, Health, Education, Child Protection, Environment
- **Rich filters**: Domain, Organization, Architecture, Model Size, Model Type
- **JSON Preview Card**: Beautiful preview of benchmark results before submission
- **Bilingual**: Full English & French documentation
- **Gold/Silver/Bronze**: Top-3 highlighting per leaderboard
